# Локальное клонирование голоса

Base-модели Qwen3-TTS могут синтезировать речь по локальному референсному WAV.
Это отдельный сценарий от `0.6B-CustomVoice` с предустановленными голосами.
Постоянный профиль Base-голоса хранит метаданные референса на диске, а
model-ready prompt создаётся один раз для текущего постоянного worker-процесса.

Локальный референс `kraftwerk_robot_3_ru.wav` длится 4.344 секунды и был
smoke-проверен через C++ CLI с кэшированной моделью `1.7B-Base`. Нескольких
секунд чистой речи может быть достаточно, но качество зависит от записи,
точности транскрипта и целевого текста.

## Создание, проба и сохранение профиля

Для создания профиля есть отдельная команда: она проверяет WAV, запускает
короткую пробную генерацию и предлагает явно сохранить либо отбросить профиль.
Создание профиля не превращает каждый обычный запрос в новое клонирование.

```powershell
.\scripts\new-qwen-tts-voice-profile.ps1 `
  -VoiceId kraftwerk_robot_ru `
  -ReferenceAudioPath .\examples\assets\kraftwerk_robot_3_ru.wav `
  -ReferenceText 'Я твой слуга, я твой работник' `
  -TestText 'Я твой робот. Я твой работник.'
```

`-Save` пропускает финальный вопрос о сохранении. По умолчанию профиль пишется
в игнорируемый Git файл `config/voice-profiles.local.json`. Можно начать и с
готового примера:

```powershell
Copy-Item config\voice-profiles.example.json config\voice-profiles.local.json
```

Скрипт использует локально кэшированную `Qwen/Qwen3-TTS-12Hz-1.7B-Base`, если
она доступна, и vendored исходники `Qwen3-TTS-streaming` из репозитория. Чтобы
выбрать другой локальный snapshot или Hugging Face model ID, передайте
`-ModelPath`.

## Использование сохранённого профиля

Выберите зарегистрированный голос при запуске Base playback-примера:

```powershell
.\scripts\start-qwen-tts-clone-play.ps1 `
  -VoiceRegistryPath .\config\voice-profiles.local.json `
  -VoiceId kraftwerk_robot_ru `
  -Interactive
```

В интерактивном CLI `/voices` выводит ID профилей, объявленных worker-ом, а
`/voice kraftwerk_robot_ru` выбирает один из них для следующих запросов. Новая
строка текста, как обычно, отменяет предыдущую генерацию.

JSON реестра хранит долговечные метаданные, а не сериализованный GPU prompt. В
запущенном worker выбранный профиль превращается в prompt Base-модели один раз
и остаётся в ограниченном LRU-кэше. После перезапуска worker prompt создаётся
при первом использовании снова, но профиль не нужно заново создавать или
вводить вручную.

Проверка принимает только локальные несжатые PCM WAV: mono или stereo, 8--96
kHz, 8/16/24/32 bit, 2--15 секунд, не тишину и не более 16 MiB. Для ICL-профиля
нужен точный транскрипт. `-XVectorOnly` -- явный запасной режим без него.

Пример в репозитории является предоставленной владельцем, восстановленной и
обработанной записью; владелец подтвердил разрешение на публикацию. Происхождение
и SHA-256 описаны в [`examples/assets/README.md`](../examples/assets/README.md).
Результат всё равно синтезирован. Используйте только разрешённые референсы,
помечайте результат как синтезированный и не применяйте профили для имитации
реального человека.
